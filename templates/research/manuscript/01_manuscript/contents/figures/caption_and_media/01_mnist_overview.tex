\caption{\textbf{MNIST classification with two classifiers.}\\
\smallskip
\textbf{A}, The first test image of each digit class.
\textbf{B}, Confusion matrix of the RBF support-vector machine on the test set:
each row is one true digit, coloured by the fraction of its test images
assigned to each predicted digit (white, 0; dark blue, 1).
\textbf{C}, Per-class recall (fraction of each digit's test images classified
correctly) of logistic regression and the support-vector machine.
}
