# Write an experiment script

```python
import scitex_io as io
from scitex_session import INJECTED, session

@session(seed=42)
def main(logger=INJECTED):
    data = io.load("./data/my_experiment/input.json")
    results = {"count": len(data)}
    io.save(results, "results.json", symlink_to="./data/my_experiment")
    logger.info("Saved measured results")
    return 0

if __name__ == "__main__":
    raise SystemExit(main())
```

Copy `scripts/template.py`, number processing scripts in execution order,
and use public `io.load/save` inside a session to record dependencies. Use
`rngg=INJECTED` for the session's random-state manager when needed.

Session output directories are generated by the installed session package;
inspect actual outputs rather than assuming a historical layout. Use
`symlink_to=` to expose outputs under `data/`. A raw JSON write does not
substitute for recorded IO. Keep Sources and Claims under researcher
control and never fill missing observations with invented values.
